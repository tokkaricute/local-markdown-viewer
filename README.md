# Local Markdown Viewer

軽量でオフライン動作を前提とした、MarkdownのプレビューおよびMermaid図表のレンダリング・高解像度書き出しができるウェブアプリケーションです。

## 特徴

- **リアルタイム Markdown プレビュー**: `marked.js` を使用して、入力内容を即座にレンダリングします。
- **Mermaid.js 統合**: フローチャート、シーケンス図、状態遷移図などの複雑な図表を簡単に描画できます。
- **高解像度書き出し**: キャンバス・スケーリング技術により、高画質（600 DPI相当）の PNG 画像として図表をダウンロードできます。
- **スマート・ネーミング**: 書き出しされるファイル名に、Markdown 内の直前の見出し（h1〜h6）を自動的に使用します。
- **オフラインファースト**: ローカルの JS ファイルを使用するため、インターネット環境がなくても動作します。
- **プレビューモード**: 新しいウィンドウでプレビューを表示し、執筆や閲覧に集中できる環境を提供します。

## 使い方

### 準備

特別なインストールは必要ありません。最新のウェブブラウザ（Chrome, Firefox, Edge, Safariなど）があれば動作します。

### インストール

1. このリポジトリをクローンするか、ソースコードをダウンロードします。
2. `index.html` と同じディレクトリに以下のファイルがあることを確認してください：
    - `index.html`
    - `mermaid.min.js`
    - `marked.min.js`
3. `index.html` をブラウザで開きます。

## 操作方法

### 編集とプレビュー
- **エディタ**: 左側のペインに Markdown コンテンツを入力します。
- **プレビュー**: 右側のペインにレンダリング結果が表示されます。入力に合わせて自動的に更新されます。

### 図表の書き出し
1. エディタに以下の構文で Mermaid 図表を入力します：
    ```mermaid
    graph TD;
        A-->B;
    ```
2. レンダリングが完了するのを待ちます。
3. 図表の下に表示される **[Download PNG]** ボタンをクリックします。
4. 直前の見出しに基づいたファイル名（例：`Section-Name-1.png`）で保存されます。

### プレビューモード
エディタのヘッダーにある **[Open in New Window]** ボタンをクリックすると、レンダリングされた内容が新しいタブ/ウィンドウで開かれ、閲覧に最適な状態で表示されます。

## 技術仕様

- **レンダリングエンジン**: Markdown には `marked.js`、図表には `mermaid.js` を使用しています。
- **高解像度ロジック**: オフスクリーン・キャンバスで $6\times$ のスケール倍率を適用し、高DPI品質を実現しています。
- **見出し検出**: DOMツリーを遡るロジックにより、直前の見出しを確実に特定してファイル名に適用します。
